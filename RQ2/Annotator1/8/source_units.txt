i1: To start the ExpenseReport process, begin by clicking on "Start" and then selecting "Edit Report".
i2: If the expense is greater than 1000, the report should be reviewed.
i3: However, if the expense is less than or equal to 1000, you should proceed to check if there is a need for translation.
i4: If translation is required, proceed to translate the receipts. If not, confirm the receipts.
i5: After this, evaluate the review decision.
i6: If the report is rejected, edit the report. If it is approved, continue to check if there is a need for translation.
i7: If the report is rejected, edit the report.
i8: Once again, evaluate the review decision.
i9: If it is approved, translate the receipts and then confirm them.
i10: Finally, evaluate the receipts decision.
i11: If the receipts are accepted, proceed to process the expense.
i12: If they are rejected, edit the report.
i13: The process ends by processing the expense and then ending it.
