i1: For developers practicing BPMN execution TDD, the first step is to understand the BPMN Model.
i2: After that, they should write a failing test.
i3: To make the test pass, they need to extend BPMN/mocks.
i4: Once the test is green, they should check if the level satisfies the project requirements.
i5: If it does, the process ends.
i6: If not, they should continue the process.
i7: If the test is not green, they should upgrade the test level.
i8: After that, they need to check if the level satisfies the project requirements again.
i9: If not, they should upgrade the test level once more.
